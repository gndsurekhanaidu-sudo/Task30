# Task30
Descriptive Statistics Using Python

Project Overview

This project focuses on calculating and interpreting descriptive statistics using Python. It helps understand numerical data through different statistical measures.

Objective

To build a foundation in statistics required for Data Science by analysing numerical data.

Dataset

Student Performance Dataset

The dataset contains three numerical variables:

- Math Scores
- Reading Scores
- Writing Scores

A sample dataset of 10 student records was created for this project.

Tools and Technologies

- Python
- Pandas
- NumPy
- Google Colab

Statistical Calculations

The following statistical measures were calculated:

1. Mean
2. Median
3. Mode
4. Range
5. Variance
6. Standard Deviation
7. Quartiles
8. Percentiles

Implementation

- Created a student performance dataset using Pandas.
- Used "describe()" to generate a statistical summary.
- Calculated central tendency measures.
- Calculated dispersion measures.
- Analysed quartiles and percentiles.
- Compared mean and median values.

Results

The project provides a statistical summary of three numerical variables and helps understand the distribution and spread of student marks.

Conclusion

This project helped me understand the basic concepts of descriptive statistics and gain practical experience using Python, Pandas and NumPy for data analysis.
